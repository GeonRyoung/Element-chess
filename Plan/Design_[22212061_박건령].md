## 1. Introduction
#### Summary
본 문서는 'Net-Iocp' 프로젝트의 분석 단계를 거쳐 도출된 요구된 요구사항을 바탕으로, 시스탬의 구체적인 설계 방안을 기술한 최종 기술 설계서입니다. 본설계서는 시스템의 정적 구조를 정의하는 클래스 다이어그램, 객체간의 동적 상호작용을 나타내는 시퀀스 다이어그램, 그리고 시스템의 상태 변화를 명시하는 상태 머신 다이어그램을 상세히 정의합니다. 이를 통해 실제 구현 단계에서 발생할 수 있는 모호성을 제기하고, 개발자에게 명확한 구현 가이드를 제공하는 것을 목적으로 합니다.

#### Introduce
본 시스템은 대규모 동시 접속자가 발생하는 환경에서도 낮은 지연 시간과 높은 처리량을 보장해야 하는 고성능 게임 서버 엔진을 지향합니다. 시스템의 핵심 기술적 특징은 다음과 같습니다.
- **IOCP 기반 비동기 엔진**: Windows 플랫폼의 I/O 모델인 IOCP를 네트워크 최하단 계층에 배치하여 비동기 처리 성능을 극대화했습니다.
- **RUDP**: UDP의 빠른 전송 속도를 유지하면서도 애플리케이션 계층이ㅔ서 Reliable UDP 매커니즘을 구현하여 데이터 전송의 신뢰성을 확보했습니다.
- **공간 분할 최적화**: 수많ㅇ느 객체 간의 상호작용 연산 비용을 절감하기 위해 Sector 기반 공간 분할 알고리즘을 적용했습니다.
- **Modern C++ 표준 활용**: C++/17/20 표준의 기능을 적극 도입하여 메모리 안전성을 높이고 효율적인 동시성 제어가 가능한 아키텍처를 설계했습니다.

#### Goals
본 설계의 최종 목표는 고성능 및 고신뢰성을 갖춘 서버 아케틱철르 구축하는 것이며, 세부 목표는 다음과 같습니다.
- **구현 모호성 제거**: 분석 단계의 유스케이스를 구체적인 시퀀스 및 클래스 구조로 변환하여 설계와 구현 간의 간극을 최소화합니다.
- **시스템 확장성 확보**: 비동기 엔진과 공간 분할 알고리즘을 통해 대규모 접속자 수용이 가능한 확장성 있는 구조를 설계합니다.
- **안정적인 상태 관리**: 클라이언트와 서버의 복잡한 상태 변화를 상태 머신 다이어그램으로 정의하여 예외상황에서도 안정적인 서비스 유지를 가능하게 합니다.
- **효율적인 자원 관리**: 최신 C++ 표준 기술을 활용하여 불필요한 자원 낭비를 줄이고 서버 운여의 효율성을 극대화합니다.

## 2. Class Diagram
본 시스템은 크게 네트워크 입출력을 담당하는 ```IOCP Layer```, 세션 및 패킷 신뢰성을 관리하는 ```Session Layer```, 게임의 비즈니스 로직을 처리하는 ```Logic Layer```, 그리고 시스템의 상태를 감시하는 ```Monitoring Layer```로 계층화하여 설계되었습니다. 각 계층은 인터페이스를 통해 결합도를 낮추고 독립적인 테스트와 확장을 용이하게 합니다.
